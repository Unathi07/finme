# Roadmap

Planning uses two-week sprints, 8–12 hours per person per week. Dates remain unset until both developers confirm availability. Estimates are planning points, not hours.

1. Foundation and first features: app scaffolding, DB foundation, API contract, transactions MVP, income MVP, integration, tests, local demo.
2. Authentication and security: registration/login, password hashing, user ownership, protected financial routes, security tests.
3. Budgets and savings: monthly/category budgets, savings goals, deterministic progress.
4. Debt and dashboard: debt tracking, repayment calculations, summary cards, charts, monthly reports.
5. AI foundation: OpenAI integration, authorised retrieval tools, tool calling, chat UI, guardrails, tests.
6. Advanced AI: insights, forecasts, savings/debt analysis, report generation, accuracy evaluation.
7. Quality and security: integration/e2e tests, hardening, errors, performance.
8. Deployment and portfolio: CI/CD, deployment decision, monitoring, docs, screenshots, demo.

Dependencies: PostgreSQL/API contracts precede feature integration; authentication and ownership precede exposure of financial data; AI tools depend on secure read APIs and deterministic services. Re-plan after each sprint review.
